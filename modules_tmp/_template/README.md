# テンプレートモジュール

このディレクトリは新しいモジュールを作成する際のテンプレートです。

## 使い方

1. このディレクトリをコピーして新しいモジュール名でリネーム
2. `module_config.json`を編集してモジュール情報を設定
3. `interface.py`を編集してモジュールの機能を実装
4. 必要に応じて`app.py`を編集して単体実行機能を実装

## ファイル構成

- `module_config.json`: モジュールのメタデータ定義
- `interface.py`: 統合用インターフェース実装
- `app.py`: 単体実行用Flaskアプリケーション
- `requirements.txt`: モジュール固有の依存関係
- `README.md`: モジュールのドキュメント

## 開発の流れ

1. **単体開発**: `python app.py`でモジュールを単独で起動してデバッグ
2. **統合テスト**: コアシステムから`interface.py`経由で呼び出されることを確認
3. **フロー組み込み**: フローデザイナーで使用可能になることを確認
